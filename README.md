# Python Basics: Sum of Two Numbers | Python Básico: Somando Dois Números

This repository contains the third practical exercise from the Programming Language Paradigms course (Digital Games Degree). The goal is to demonstrate basic primitive types and mathematical operations in Python using a simple procedural approach.

Este repositório contém o terceiro exercício prático da disciplina de Paradigmas de Linguagem de Programação (curso de Jogos Digitais). O objetivo é demonstrar os tipos primitivos básicos e operações matemáticas em Python usando uma abordagem procedural simples.

## 💻 About the Project | Sobre o Projeto

The script executes sequentially, prompting the user for two numbers via the terminal, converting the input to integers, and returning a formatted string with the sum using `f-strings`. It was developed in two versions (English and Brazilian Portuguese).

O script é executado de forma sequencial, pedindo ao usuário dois números via terminal, convertendo a entrada para inteiros e retornando uma string formatada com a soma usando `f-strings`. Foi desenvolvido em duas versões (Inglês e Português Brasileiro).
